# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-08-27

- Add binary UART framing and command support for BP35C0-J11 adapters.
- Add ECHONET Lite smart-meter property decoding.
- Add asynchronous serial sessions with bounded reads, cached-network rejoin,
  reconnect/backoff, authentication lockout protection, and live diagnostics.
- Support RATOC RS-WSUHA-J11 and ROHM BP35C2-J11-T01 hardware.
- Publish a typed public API for Home Assistant and other Python consumers.
